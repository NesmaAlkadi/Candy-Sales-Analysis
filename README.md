# Candy-Sales-Analysis

## 🎯 Objective  
Analyze and visualize **candy sales performance** using **Excel (PivotTables, Power Query, and Power Pivot)** to uncover:
- Sales trends  
- Best-selling products  
- Regional performance  
- Improvement opportunities
  
## 📊 Overview  
This project demonstrates how **Excel’s advanced features** can turn raw data into clear, actionable insights.  
The analysis explores **sales distribution, profitability, and efficiency** to support data-driven decision-making.  

## ⚙️ Process  

### 1. 🧹 Data Cleaning  
- Removed duplicates & inconsistencies  
- Standardized formats (dates, regions, categories)  
- Loaded and transformed data with **Power Query**

### 2. 🧩 Data Modeling  
- Created data relationships in **Power Pivot**  
- Defined **DAX calculations** for profit, cost, and KPIs  

### 3. 📈 Visualization  
- Built interactive **PivotTables & Charts**  
- Added **Slicers** for dynamic filtering  
- Designed a clean dashboard for clear storytelling

## 🧠 Tools & Features  
| Tool | Purpose |
|------|----------|
| **Excel Power Query** | Data extraction & cleaning |
| **Power Pivot** | Data modeling & DAX calculations |
| **PivotTables & Charts** | Data exploration & visuals |
| **Slicers & KPIs** | Interactive dashboard elements |

## 🔍 Key Insights  

### 💵 Overall Performance  
- **Total Sales:** 141K  
- **Gross Profit:** 93K  
- **Orders:** 8.5K from **5K Customers**

### 🚚 Orders & Shipping  
- Majority of orders shipped via **Standard Class**

### 🌎 Regions & Products  
- **Top Region:** Pacific (46K)  
- **Top Product:** *Wonka Bar – Triple Dazzle Caramel*  
- **Best-Selling Division:** Chocolate (132K)

## 🏁 Conclusion  
This project highlights the power of **Excel** as a full analytical tool — from **data cleaning** to **dashboard creation**.  
By Power Query, Power Pivot, and PivotTables, we can extract meaningful insights that drive smarter business strategies.
